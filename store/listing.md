## Name

Prompty — Global Prompt Library

## Summary (CWS ≤ 132 characters, AMO ≤ 250)

Save, organize and insert prompts anywhere, compose AI-video shots, and keep it all local or encrypted.

## Category

Productivity (CWS: Workflow & Planning · AMO: Productivity)

## Description

Prompty keeps your prompt library one keystroke away on every site: ChatGPT, Claude, Gemini,
Perplexity, Higgsfield, Dreamina, meta.ai, or any plain text box.

It is built for people who direct AI images and video. Beyond saving prompts, it composes them the
way a director briefs a crew.

**Your library, everywhere**

- Save from any page: the right-click menu, `Alt+Shift+S`, or the pill that appears on prompt boxes.
- Insert at the cursor: from the popup, the floating widget, or by typing `!` in any input.
- `Ctrl/Cmd+K`: one keyboard-only palette for prompts, snippets and commands.
- 52 cinematic starter prompts in 16 categories: camera movement, lighting, lens & optics,
  locations, color grading, composition, mood, VFX & transitions, posters, logos and more.

**Prompts that become shot generators**

- `{lens:24mm|50mm|85mm}` choices, `{seed:1-999}` ranges with a dice roll, `{mood=calm}` defaults.
- A fill-in form with live preview that remembers what you used last.

**Direct a scene**

- **Composer**: build a shot from film-grammar blocks (subject, location, camera, lens,
  composition, lighting, grade, mood, transition), each picked from your library or written by
  hand.
- **Sequences**: chain shots with a duration and the cut between them (hard cut, match cut, smash
  cut, whip pan, dissolve, or one continuous take). A variable like `{hero}` is asked once and keeps
  the same character in every shot.
- **Model dialects**: write the scene the way the model reads it. Seedance 2.5 gets time ranges and
  cut events; Muse Video gets `STOP. HARD CUT.` shots. Prompty suggests the dialect for the site
  you're on and warns when a sequence fights the model.

**Know what works**

- **Insights**: most-used prompts, uses by category, prompts added per month, never-used and
  dormant (90+ days) prompts, and recent fill-ins. Computed from what Prompty already stores;
  nothing new is tracked. Tick **Select these** to hand a dormant list to the bulk bar.

**Stay organized**

- Categories with drag-to-reorder, tags, favorites, search and sort.
- Bulk select to move, tag, star, copy, export or delete, with a 10-second undo.
- Version history: compare any earlier take word by word and restore it.
- **Import from another tool**: read a Prompty or Higgsfield export, CSV, text/Markdown or JSON,
  de-duplicate automatically and see a merge report.
- **Share packs**: select prompts and save a `.prompty` file with their categories and Composer
  blocks; drop one on the popup to preview and import it.
- Large libraries stay fast: 5,000 prompts open in about 0.3 s.

**Private by design**

Everything stays in your browser's local extension storage. Prompty makes no network requests, has
no account and collects no analytics.

- **Vault Mode** (optional): encrypt prompts, snippets, fill-in memory and Composer drafts with a
  passphrase (AES-GCM-256, PBKDF2-SHA-256 at 250k iterations). The key is held in memory only and
  the vault auto-locks. There is no passphrase recovery.

## Privacy practices (CWS) / data collection (AMO)

- Data collected: **none**. Prompts, settings and history stay in `storage.local` on the device.
- No remote code; no network requests.
- Vault Mode is optional and on-device only: the passphrase, key and ciphertext never leave the
  browser.
- Single purpose: save, organize, compose and insert text prompts.

## Permission justifications

| Permission               | Why                                                                                                          |
| ------------------------ | ------------------------------------------------------------------------------------------------------------ |
| `storage`                | Keep the prompt library, settings, drafts and history on the device.                                         |
| `activeTab`, `tabs`      | Insert into the page you're on, and read its address so the Composer can suggest that site's prompt dialect. |
| `contextMenus`           | "Save selection as prompt" in the right-click menu.                                                          |
| `notifications`          | Confirm a save made from the context menu or shortcut when the page can't show its own message.              |
| Host access `<all_urls>` | The in-page pill, floating widget and `!` palette work in prompt boxes on any site the user visits.          |

## Shortcuts

`Alt+P` open library · `Alt+Shift+S` save selection · `Alt+Shift+W` toggle widget ·
`Ctrl/Cmd+K` palette (in the popup) · `!` quick insert (in any input; configurable)

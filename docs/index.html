Features

A library, a composer, and a command palette — all yours.

Everything stays in browser.storage.local. Prompty reads it, writes to it, and never phones home.

The library, at a glance

Browse by category, search by tag, star and reorder. Each card shows its variables, use count and one-tap Insert · Append · Copy.

Fill-in that remembers

Prompts with {subject}, {lens:24mm|50mm} or {seed:1-999} render a live form. Last-used values are remembered per session.

One keystroke, every prompt

Recency-weighted, fuzzy-matched, keyboard-only. Open it with Ctrl/⌘ K, or type ! in any input to launch it at the caret.

Your agent can write here

Point Claude Code, Cursor or any MCP client at mcp/server.mjs and ask for “a camera movement for a slow dolly zoom.” It appears in Prompty within a minute, over an opt-in, token-paired loopback bridge. Off by default, no cloud, no account.

Quick insert

Type ! in any input and a fuzzy palette opens at the caret.

Shot composer

Build a shot from film-grammar blocks, chain shots into a scene, write it the way the model reads it.

Vault mode

Opt-in AES-GCM encryption at rest. Your passphrase never leaves the browser.

Import · share · export

Migrate from Higgsfield, CSV, Markdown or JSON with a merge report. Share a selection as a .prompty pack; drop one on the popup to import.

Insights

Most-used prompts, uses by category, prompts added per month, and never-used / dormant items — computed from what it already stores.

How it works

From thought to prompt, without leaving the input.

01 — Capture

Save anything, anywhere

Right-click → save selection, the floating pill, or Alt+Shift+S. Prompty anchors to the save button and fields of the site you're on via per-site recipes.

! palette · context menu
02 — Organize

Categorize, tag, version

Drag cards between categories, bulk-select with Ctrl+A, keep version history with word-level diffs, and undo any delete for 10 seconds.

Ctrl/⌘ + K
03 — Paste

Insert at the caret

Insert, append or copy into the focused box on any site. Variables are filled in once and reused. The in-page palette asks the background — pages never see your key.

Enter to insert
Privacy by design

Built for people who don't want a second account.

Prompty has no login, no cloud, no analytics and no remote code. Your prompts live in your browser's local storage — and if you turn on Vault Mode, they're encrypted before they're written.

  • ✓ All data in browser.storage.local on your device
  • ✓ No cloud requests, no telemetry; the agent bridge is opt-in and loopback-only
  • ✓ Optional Vault Mode: AES-GCM-256, PBKDF2-SHA-256 at 250k iterations
  • ✓ Export is a plain file you hold; import is a report you approve

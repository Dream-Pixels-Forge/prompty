Features

Prompt library

Browse by view/category, search, sort, star, insert/append/copy/edit/delete with undo.

Cinematic starter

52 prompts across 16 categories. Variables like {subject}, {lens:24mm|50mm}, {seed:1-999}.

Command palette

Ctrl/Cmd+K for prompts, snippets and commands, keyboard-first.

Quick insert

Type ! in any input for fuzzy palette at the caret.

Site recipes

Data-driven anchors for AI sites + custom JSON recipes.

Assist UI

Smart pill + floating widget, clipboard snippets, context menu shortcuts.

No network. No accounts. All data in browser.storage.local.

Architecture

Dual manifest build

One source → dist/chrome service worker MV3 and dist/firefox event page MV3. Shared assets copied per target.

Background

Service worker/event page handles storage sync, commands, context menus, settings migration and seed presets. No network.

Content script

Shadow DOM assist UI: pill, floating widget, ! palette, insert/append/save handlers. Passive unless user triggered.

Popup UI

Library, editor, categories, snippets, settings, command palette. Pure DOM, no frameworks.

Lib modules

Pure ES modules: storage, variables, search, recipes, sites, text, message, diff, capture. Fully tested.

Quality gates

Vitest 304 tests, TypeScript check, ESLint, web-ext lint, addons-linter. CI on every PR.

100% local · browser.storage.local only · zero telemetry

## Goal: G8 — Accessibility and translation baseline

> **Status: G8a (accessibility) done; G8b (translation) open.** G8 is split in two because moving
> every UI string to `_locales/` touches every popup file, and that is better as its own PR.
>
> G8a findings from axe-core 4.10 (`scripts/a11y-audit.mjs`), across 9 views × light/dark, all
> fixed (0 violations):
>
> - **Critical:** the Composer's shot `tablist` contained a non-tab (+ Shot). Tabs now sit in their
>   own list; the cut labels are `aria-hidden`; each tab is named, e.g. "Shot 2, 3 seconds, after
>   a match cut".
> - **Serious:** scrollable regions (the Composer preview, the main view) had no keyboard access;
>   both are now focusable and named.
> - The three sidebar `<nav>` landmarks had no labels. They are now named "Views", "Categories" and
>   "Settings".
> - `role="dialog"` was set on `<form>`, which ARIA doesn't allow; it moved to the overlay, which
>   is labelled by the dialog title.
>
> Beyond axe:
>
> - The whole view was an `aria-live` region, so a screen reader re-read the grid on every render
>   (toasts already announce changes). The Composer preview announced every keystroke. Both are
>   removed.
> - Modals and the palette now trap Tab and Shift+Tab (`aria-modal`).
> - `prefers-reduced-motion` stops transitions and animations.
>
> Not covered yet: the in-page UI in the content script's shadow DOM (pill, widget, `!` palette),
> which needs its own audit harness on a test page.

### Objective

Everything in the popup and the in-page UI works by keyboard and screen reader and passes
WCAG 2.1 AA contrast. All UI strings move into `_locales/` so the extension can be translated.
French is the first translation.

### Deliverables

- [x] Accessibility audit with fixes (G8a):
  - focus order, visible focus rings, roles and labels on icon buttons
  - `aria-live` regions for toasts
  - modals trap focus
  - `prefers-reduced-motion` respected
- [ ] `_locales/en/messages.json` plus `fr`; a `t(key, …subs)` helper (`browser.i18n`, with a
      fallback in tests); manifest name and description translated.
- [ ] A test that fails when a UI string is not in the catalog (scan for literal strings passed to
      `h()` text children in `src/popup`).

### Definition of Done

- [ ] axe-core run in headless Chromium with 0 serious issues; keyboard-only e2e of each view; a
      French screenshot; gates green.

### Anti-Drift Rules

- Prompt contents and seed prompts are user data, not UI strings: they are not translated.
